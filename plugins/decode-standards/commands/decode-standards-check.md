Review the working tree against DECODE's engineering standards.

1. Read the `decode-standards` skill for the current house rules.
2. Run `git status` and `git diff` to see what has changed.
3. Report only concrete deviations from the documented standards, each with a
   file and line reference. If a standard is still a TODO stub in the skill,
   say so rather than inventing a rule.
4. Do not change any files unless asked.
